## Web UI 使用指南

### 🎉 功能特性

Ani2Openlist Web UI 提供了一个友好的图形界面，让您可以轻松管理配置和任务。

#### 主要功能

1. **配置管理** - 通过 Web 界面编辑配置文件
2. **手动执行** - 一键运行同步任务
3. **定时任务** - 设置自动运行计划
4. **日志查看** - 实时查看运行日志
5. **状态监控** - 查看任务运行状态

---

### 📦 安装依赖

首先需要安装 Web UI 所需的额外依赖：

```bash
pip install Flask>=3.0.0 APScheduler>=3.10.0
```

或者直接安装所有依赖：

```bash
pip install -r requirements.txt
```

---

### 🚀 启动 Web UI

```bash
python webui_start.py
```

启动后，您会看到类似的输出：

```
============================================================
🎬 Ani2Openlist Web UI
============================================================

正在启动 Web 服务器...

访问地址：
  - 本地访问: http://localhost:5000
  - 局域网访问: http://您的IP:5000

按 Ctrl+C 停止服务
============================================================
```

### 📋 功能说明

#### 1. 仪表板

首页显示任务状态和最近日志：

- **任务状态**: 显示当前是否有任务正在运行
- **上次运行时间**: 显示最后一次任务执行的时间
- **上次运行结果**: 显示任务执行成功或失败
- **最近日志**: 显示最近 5 条日志
- **立即运行**: 点击按钮手动执行任务

#### 2. 配置管理

编辑 `config.yaml` 配置文件：

**Openlist 服务器配置**
- 服务器地址（必填）
- 用户名/密码 或 Token（二选一）
- 目标目录（必填）

**ANI Open 配置**
- RSS 追更模式（开/关）
- 手动模式：年份、季度、关键字
- 源域名和 RSS 域名（可自定义反代）

**日志配置**
- 日志级别（DEBUG/INFO/WARNING/ERROR）
- 日志格式

保存后配置会立即生效（下次运行时使用新配置）。

#### 3. 定时任务

设置自动运行计划：

**每天执行**
- 选择每天的执行时间
- 例如：每天 10:00 执行

**间隔执行**
- 设置间隔小时数
- 例如：每 6 小时执行一次

**自定义 Cron**
- 使用 Cron 表达式
- 例如：
  - `0 10 * * *` - 每天 10:00
  - `0 */6 * * *` - 每 6 小时
  - `0 10 * * 1` - 每周一 10:00
  - `0 10 1 * *` - 每月 1 日 10:00

**任务列表**
- 显示当前所有定时任务
- 显示下次运行时间

#### 4. 日志查看

查看所有运行日志：

- **自动刷新**: 默认每 5 秒自动刷新
- **手动刷新**: 点击刷新按钮
- **清空日志**: 清除所有历史日志

日志级别：
- 🟢 **SUCCESS**: 成功操作
- 🔵 **INFO**: 一般信息
- 🟡 **WARNING**: 警告信息
- 🔴 **ERROR**: 错误信息

### 💡 使用技巧

#### 1. 首次使用

1. 启动 Web UI
2. 进入"配置"页面
3. 填写 Openlist 服务器信息
4. 保存配置
5. 返回仪表板，点击"立即运行"测试

#### 2. 设置定时任务

1. 进入"定时任务"页面
2. 勾选"启用定时任务"
3. 选择任务类型和时间
4. 保存配置
5. 查看任务列表确认

#### 3. 监控运行状态

1. 在仪表板可以看到任务是否正在运行
2. 查看最近日志了解执行情况
3. 进入"日志"页面查看详细日志

#### 4. 手动执行任务

1. 在仪表板点击"立即运行"
2. 任务会在后台执行
3. 页面会自动更新状态
4. 执行完成后显示结果

### 🔧 配置文件位置

- **应用配置**: `config.yaml` (项目根目录)
- **定时任务配置**: `webui/schedule.yaml` (自动创建)

### ⚙️ 高级设置

#### 修改端口

编辑 `webui_start.py` 或 `webui/app.py`：

```python
app.run(host='0.0.0.0', port=5000, debug=False)
#                            ^^^^ 修改这里
```

#### 启用调试模式

不推荐在生产环境使用：

```python
app.run(host='0.0.0.0', port=5000, debug=True)
#                                         ^^^^ 改为 True
```

#### 局域网访问

确保防火墙允许 5000 端口访问，然后在其他设备上访问：

```
http://您的电脑IP:5000
```

### 🐛 故障排查

#### 问题 1: 无法启动

**错误**: `ModuleNotFoundError: No module named 'flask'`

**解决**:
```bash
pip install Flask APScheduler
```

#### 问题 2: 端口被占用

**错误**: `Address already in use`

**解决**: 
- 更改端口（见高级设置）
- 或关闭占用 5000 端口的程序

#### 问题 3: 任务执行失败

**检查**:
1. 查看日志页面的错误信息
2. 检查配置是否正确
3. 确认 Openlist 服务器是否可访问

#### 问题 4: 定时任务不运行

**检查**:
1. 确认已勾选"启用定时任务"
2. 查看任务列表中的下次运行时间
3. 保持 Web UI 程序运行（不能关闭）

---

### 🔐 安全建议

1. **不要将 Web UI 暴露到公网**
   - 仅在内网使用
   - 如需公网访问，请使用反向代理并添加认证

2. **修改默认密钥**
   - 编辑 `webui/app.py`
   - 修改 `SECRET_KEY` 为随机字符串

3. **使用 Token 认证**
   - 推荐使用 Openlist Token 而不是用户名密码
   - Token 更安全且不会过期

---

### 📝 注意事项

1. **保持程序运行**
   - 定时任务需要 Web UI 程序持续运行
   - 可以使用 systemd、supervisor 等工具实现开机自启

2. **配置实时生效**
   - 配置修改保存后立即生效
   - 但正在运行的任务不受影响

3. **日志自动清理**
   - Web UI 只保留最近 100 条日志
   - 如需长期保存，请查看应用程序日志文件

4. **定时任务精度**
   - 定时任务使用 APScheduler
   - 精度为秒级，足够日常使用
